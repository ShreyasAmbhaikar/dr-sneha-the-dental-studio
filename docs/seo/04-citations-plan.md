## Rules

1. Same name, address, phone, hours and website on every listing — no abbreviations ("Opp." everywhere, "Shop No. 2/3/4" everywhere).
2. Same logo, cover photo and 5–10 core photos.
3. One listing per platform; search first and **claim** an existing listing instead of creating a duplicate.
4. Three a week (Mon/Wed/Fri) — a steady pace looks natural; a burst does not.
5. Record the listing URL and login owner in the CSV the same day.
6. Free listings only unless a paid plan is consciously budgeted (Justdial and Practo will upsell).
